# student-marks-analyzer

**Student Marks Analyzer** is a Python-based mini project designed to manage and analyze students' marks efficiently. The program takes student names and marks as input and generates a detailed student performance report.

The system calculates the **total and average marks**, identifies the **highest and lowest marks**, assigns **grades**, searches for a particular student, and ranks students based on their marks.

**Technologies Used:** Python

**Key Concepts:** Lists, Loops, Functions, Conditional Statements, Searching, Sorting, `max()`, `min()`, `sum()`, and Lambda Functions.

**Key Features:**

* Add student names and marks
* Calculate total and average marks
* Find highest and lowest marks
* Automatically assign grades
* Search for a student
* Rank students based on marks
* Display a complete student performance report
